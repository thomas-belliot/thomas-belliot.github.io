typewriter
==========

To run the website, look at the Github documentation [here](https://docs.github.com/en/pages/setting-up-a-github-pages-site-with-jekyll/about-github-pages-and-jekyll).
To clean the jekyll files : bundle exec jekyll clean
To build the jekyll files : bundle exec jekyll build
Once everything is set, just put in a terminal : bundle exec jekyll serve
Then click on the link containing the server address (something like http://127.0.0.1:4000).
